### 🛡️ About Me & Engineering Philosophy

> *"Great full-stack engineering is not just about delivering endpoints and rendering UI—it is about architecting resilient systems where clean frontend state, robust API contracts, and high-performance data persistence operate in complete harmony."*

I am a **Systems Engineer** and **Full Stack Software Engineer** dedicated to building performant web applications and data-intensive distributed architectures. My core delivery stack revolves around modern JavaScript/TypeScript (**React, Node.js, NestJS**), reinforced by strong systems programming foundations in **C# (.NET), Go, and low-level concurrency**.

What sets my engineering approach apart is a deep, first-principles mastery of **relational engine internals, query execution plans, and data modeling**. Rather than treating databases as opaque black boxes behind ORMs, I design schemas, indexing topologies, and transactional boundaries that prevent deadlocks, minimize disk I/O, and maintain strict data integrity under heavy production load.
